Правила оценки

Сначала проверяются доступность, тип сделки, тип объекта и заданные границы цены. Нарушение любого обязательного условия исключает объект.

Базовые веса: район {{ weights.district }}; комнаты {{ weights.rooms }}; бюджет {{ weights.budget }}. Если критерий не задан, его вес не участвует в расчете; оставшиеся веса нормализуются до 100%.

Район сравнивается по полному названию без учета регистра, лишних пробелов и различия «е/ё». Для комнат: max(0; 1 − |факт − требование| / max(требование; 1)). Для бюджета: max(0; 1 − |цена − цель| / цель); цель — середина заданного диапазона либо единственная положительная граница. Итог — взвешенная сумма, округленная до сотых.

Версия {{ version }}. Расчет детерминирован: одинаковые данные и веса дают одинаковую оценку.
